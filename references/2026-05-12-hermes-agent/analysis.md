# 2026-05-12 Hermes Agent 视觉素材分析

## 素材来源

三张 Hermes Agent 宣传/架构视觉材料，分别为：
- `01-architecture-flow.jpg` — 架构图/数据流图
- `02-four-pillars.jpg` — 四大核心能力信息图
- `03-promotional-poster.jpg` — 宣传海报

## 设计语言提取

### 整体风格
- **现代科技感 × 极简主义**，不堆砌装饰，用结构和留白说话
- 三张图虽用途不同，但共享同一套视觉语法

### 1. 配色策略

| 维度 | 观察 |
|---|---|
| **暗色系（图1）** | 深蓝/深灰底 + 蓝紫渐变模块，科技叙事专用 |
| **亮色系（图2/3）** | 纯白/米白底 + 黑字 + 橙色点缀（品牌色） |
| **品牌色** | 橙色 `#FF6B35` 近似值，作为唯一高饱和强调色 |
| **辅助色** | 灰度层级丰富，从纯黑到浅灰，不用彩色抢戏 |

**关键原则**：一套品牌，两套场景配色——暗色对内/技术，亮色对外/宣传。与我们"双轨审美"一致。

### 2. 排版与层级

- **大字号标题**：海报用超大粗体建立视觉锚点，信息图用中等字号
- **卡片式布局**：所有模块信息都封装在圆角卡片内，天然分隔、易读
- **信息层级**：标题 → 图标 → 短句描述，三级递进，不贪

### 3. 图形语言

- **圆角卡片**：统一的圆角半径（~12-16px），柔和但不幼稚
- **图标系统**：线性/面性混合图标，统一描边粗细
- **3D 元素**：图3用3D白块承载logo，增加空间感和品质感
- **连接线/箭头**（图1）：用流动线条表达数据流向，不用实框硬连

### 4. 布局模式

| 图 | 布局 |
|---|---|
| 01 | 横向流 + 左右分组（用户侧 vs Agent侧 vs 工具侧） |
| 02 | 中心辐射型（hub + 四象限卡片） |
| 03 | 海报式（大标题居中 + 悬浮卡片散落） |

### 5. 留白与呼吸感

- 卡片间距 > 卡片内边距 > 文字行距
- 海报大量留白，信息密度克制
- 不恐惧空白，用间距代替分割线

## 可复用的设计公式

1. **暗色技术图** = 深底 + 渐变模块 + 流动线条 + 等宽/无衬线字体
2. **亮色信息图** = 白/米白底 + 中心hub + 圆角卡片辐射 + 图标 + 单色点缀
3. **宣传海报** = 米白底 + 超大粗体标题 + 3D元素 + 悬浮卡片 + 橙色品牌色

## 与现有 STYLE_GUIDE 的关系

- 本次素材强化了"暗色系统风"的具体实践路径
- 橙色品牌色的使用方式可借鉴到我们的项目视觉识别中
- 卡片式 + 图标 + 短句的信息封装模式，适合后续架构图/能力图输出
