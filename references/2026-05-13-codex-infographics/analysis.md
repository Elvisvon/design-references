## 路线一：暖调杂志信息图（前3张）

### 色彩
- **主背景**：暖米色（#E8D5C0 左右），非纯白
- **标题区**：赤陶/焦糖橙渐变，视觉锚点
- **分区色块**：低饱和大地色系，每张内部色相有变化
  - 图1：芥末黄 → 灰绿 → 米白
  - 图2：同系变化
  - 图3：灰蓝 → 深青绿 → 灰绿 → 暖棕（偏冷调，但饱和度统一）
- **文字**：深棕黑，非纯黑
- **代码块底色**：比色块底色再深一档，形成三层递进

### 排版层级
- 顶部大标题（最大字号）+ 英文副标题（小字号压底）
- 分区编号 01/02/03/04：橙色粗体无衬线，既是导航又是装饰
- 正文两层：小标题加粗 → 正文常规
- 行距：1.5-1.6 倍，内容密集时略收紧段间距

### 布局与留白
- 单列纵向，三段/四段式等宽分布
- 色块内部统一 padding
- 截图/图表嵌入：圆角+极细描边（非纯黑），不打断阅读流
- 图表配色服从色块色系，不引入新色相

### 骨架（可复用三件套）
1. 编号 + 色块（视觉锚点）
2. 截图/代码块/图表（内容载体）
3. emoji 路标（克制使用，每张 ≤3 个）

## 路线二：极简冷淡风清单（第4张）

### 色彩
- **主背景**：纯白（#FFFFFF）
- **文字**：纯黑/深灰
- **唯一色彩**：顶部浅蓝灰渐变条 + 右上角橙色圆点（页码）

### 排版
- 字号小，行距紧凑
- 无分区色块，用水平细线分隔条目
- 左侧 emoji 图标作为视觉锚点，替代编号
- 页码系统（01/06），系列化

### 密度
- 单页5条+顶部说明，信息密度高
- 视觉感受：挤但有序

## 新增可提炼规则

1. **编号锚点**：大号编号（01/02/03）用统一高饱和色，贯穿全篇作为视觉线索
2. **三层底色递进**：背景 → 色块 → 内嵌元素（代码/图表），每层深一档
3. **色块可换相不换饱和度**：同系列内色块色相可变，但饱和度统一在低区间
4. **emoji 克制法则**：仅作语义路标，每张 ≤3 个，不装饰
5. **冷淡风是杂志风的去色变体**：纯白底+细线替代色块+emoji替代编号，骨架不变
6. **截图/图表服从色系**：内嵌元素的配色服从父级色块，不引入新色相
