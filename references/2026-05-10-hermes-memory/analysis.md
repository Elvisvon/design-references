# 设计分析：Hermes Memory System 系列（纯视觉）

> 日期：2026-05-10 | 素材：5 张 | 来源：用户认可

## 整体视觉语言

同一套模板的 5 个变体，风格高度统一。

## 色彩

- 背景：深灰/近黑渐变，非纯黑，有微妙层次
- 主文字：白色
- 辅助文字：中灰/浅灰
- 点缀色：暖橙/琥珀色（编号、高亮线、小标签）
- 强调块：纯黑矩形（黑盒），白字
- 分割线：极细浅灰线

## 排版

- 标题：无衬线粗体，白色，左对齐
- 副标题/日期：小号灰色，右上角
- 正文：无衬线常规，白色/浅灰
- 编号：超大号无衬线数字（01/02/03/04），暖橙色，占据视觉锚点
- 层级：主标题 → 编号 + 小标题 → 正文 → 辅助说明

## 布局

- 卡片系统：圆角矩形（约 8-12px），深灰底色，承载信息块
- 卡片间距均匀，网格对齐
- 左右双栏 / 上下分块灵活切换
- 黑盒（纯黑矩形）用于核心论点，独立于卡片系统
- 信息密度高，但通过卡片边界和间距保持可读性

## 装饰元素

- 极细分割线
- 编号作为主要装饰/引导元素
- 无图标、无插画、无纹理
- 无阴影、无渐变卡片
- 无水印、无品牌 logo

## 氛围关键词

暗色、理性、高密度、卡片化、编号引导、克制、系统文档感、Notion/Linear 暗色 UI 质感

## 与已有风格对比

| 维度 | 轨道 A（已有） | 轨道 B（新增） |
|---|---|---|
| 背景 | 纸白/纯白 | 深灰/近黑 |
| 标题字体 | 衬线 | 无衬线 |
| 点缀色 | 瑞士红/水彩 | 暖橙/琥珀 |
| 布局 | 留白多、分割线 | 卡片填满、网格对齐 |
| 编号 | 无 | 大号数字锚点 |
| 信息密度 | 中等 | 高 |
| 装饰 | 水彩轻点缀 | 无装饰，纯结构 |

## 共同底层逻辑

- 克制，不炫技
- 结构清晰，层级分明
- 信息密度优先
- 零冗余装饰
